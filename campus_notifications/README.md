# Campus Notifications Microservice Deliverables

This folder contains all stage deliverables for the Campus Notifications task.

## Files

- `notification_system_design.md` (Stages 1 to 6)
- `src/stage6_priority_inbox.js` (working Stage 6 implementation)
- `output/` (generated runtime outputs and screenshot)

## Setup

1. Create `.env` from `.env.example`.
2. Fill `ACCESS_TOKEN` (preferred), or fallback auth credentials.
3. Run:

```bash
npm run stage6
```
